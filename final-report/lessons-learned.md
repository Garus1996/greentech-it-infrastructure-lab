# Lessons Learned

## Technical Learning

This project improved my understanding of how multiple infrastructure services work together in a business environment.

The most important technical lessons included:

- Active Directory depends heavily on correctly configured DNS.
- Security groups provide a scalable method for access management.
- NTFS and share permissions must be reviewed together.
- Domain Controllers should not be treated like standard member servers.
- Event logs provide valuable information for both troubleshooting and security investigations.
- Backup is incomplete until restoration has been tested.
- Automation improves consistency and reduces repetitive administrative work.
- Windows and Linux systems can be integrated within the same infrastructure.

## Troubleshooting

Troubleshooting was a major part of the project.

Problems were resolved by:

- Reading error messages carefully
- Reviewing event logs
- Validating services with PowerShell
- Testing network connectivity
- Checking firewall rules
- Confirming DNS resolution
- Verifying permissions
- Breaking larger problems into smaller tests
